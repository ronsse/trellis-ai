## 3. Lane K — the graph observes its own shape (09-12 §4, Phase 3 prerequisites)

Phase 3 needs three things before its first actuator:

- a sensor with base rates (§4.4);
- a stop the tuner cannot move (§5.3);
- producers that no longer create the defects an actuator would clean (#594 §6).

This lane builds those three, then designs the federation map's missing key. No
actuator ships here. Moving one to Tier 1 is a ladder amendment, and that amendment
is the owner's call (§5).

**K1 · `save_knowledge` stops minting orphans on a legacy type.**

- **Measure first**, read-only on prod, for the `gotcha`, `concept` and `system` nodes:
  - which property keys they carry;
  - whether any value names an existing node's deterministic id (the `tool:`,
    `artifact:`, `domain:` … scheme #577 resolves);
  - how many carry `evidence_ref`;
  - how often `relates_to` was passed (`link.create` against `entity.create` for
    `requested_by = mcp:save_knowledge`).
- **Then fix the producer**, sized by that measurement:
  - canonicalize the type on write, per ADR ontology §4.2, but only where the probe shows
    the alias fits what agents actually write;
  - resolve `relates_to` by name as well as by id, confirmed in one
    `get_subgraph(depth=0)` read as #577 does. The fix never mints a target.
- The logic goes in a new module. The `server.py` hunk stays small and is
  `git merge-tree`-checked against #558, #569, #573, #585, #587 and #592.
- **Done when** a test shows a new write landing canonical, and linked when its target
  exists, and the probe numbers are in §7.

**K2 · Graph-shape sensor: `trellis analyze graph-shape --format json`.**

- One read pass: no per-node `get_edges` and no cap. It reports:
  - type counts bucketed by alias, plus the splits the alias map does not cover;
  - cross-type name collisions;
  - the degree distribution;
  - isolated share by type;
  - external-referent share;
  - document linkage.
- These are §4.4's base rates. Every future actuator states its trigger in this
  report's terms, and states the fraction of nodes its rule would fire on before it is
  built.
- It is read-only and lives in a new module. The CLI hunk is merge-tree-checked against
  #584 and #586.
- **Done when** it reproduces #594's numbers on prod (read-only, REPEATABLE READ), and
  its exit code does not depend on `--format`.

**K5 · The immutable core (09-12 §5.3).**

- **Measure first**: what a `RuleTuner` proposal can target, and which registry keys
  govern another loop (`learning.schema_evolution`, `learning.tag_evolution`, …).
- `GOVERNING_KEYS` is a code constant. `promote_proposal` refuses those keys with a
  `TUNER_PROPOSAL_REJECTED` reason. It is the one seam the manual and Tier-1 paths share.
- The handler allowlist binds the writers that **already** run unattended
  (`trellis_workers` and the nightly jobs). None of them may issue a delete, redact or
  purge operation. It is enforced from day one, not held back for an actuator that does
  not exist yet, because a constant nothing reads is the dead code program item C1
  removes.
- Both are pinned by derived AST rules in the `test_policy_gate_rule.py` style, and each
  is proved against a synthetic violation.
- **Done when** both rules fail on their synthetic trees and pass on `src/`.

**K4 · Referent identity: the federation map's missing key (design only).**

- #594 §6 says the map needs referent identity before it needs edges.
- The seeds already exist:
  - `physical_uri` in `well_known.py`;
  - the measured locator keys: path-as-name 137, `repo` 60, `machine` 41, `host` 15,
    `file` 9, `endpoint` 4, `url` 1.
- The question is how a node names something that lives in another system, such as a
  file, a repo, a table or another graph's node. Two producers that mean the same
  referent must mint the same id.
- A decision panel on litellm `deep` (Kimi) plus Nemotron decides it. That is the
  heavier-model review the owner asked for on 09-12.
- The brief quotes the prior attempts: ontology ADR §5.1 (no migration), #577's id
  scheme and #300 (frame fidelity).
- Output: `docs/design/adr-referent-identity.md`, status *proposed*. A split panel goes
  to §5.
